# 実装ログ

このテーマリポジトリで行った実装内容を、できるだけ分かりやすくまとめました。

## 何を作ったか

- `package.json` を追加しました。
  - これはこのテーマを「パッケージ」として扱うための設定ファイルです。
  - 名前やバージョン、公開先、Slidev に必要な設定を入れています。

- `slides.md` を追加しました。
  - このファイルは「テーマを自分の手元で確認するためのスライド」です。
  - Slidev はテーマリポジトリ内でこのファイルを開くとテーマを確認できます。

- `.npmrc` を追加しました。
  - これは npm という仕組みが、どこからテーマを取ってくるかを決めるための設定です。
  - 今回は GitHub Packages という仕組みを使う想定です。

- `.github/workflows/publish.yml` を追加しました。
  - これは GitHub 上で、自動的にテーマを公開するための設定です。
  - あるタグを付けて公開すると、自動で npm に送る仕組みです。

- `layouts/default.vue` を追加しました。
  - Slidev のテーマとして使うための見た目の土台です。

- `styles/theme.css` を追加しました。
  - テーマの色や文字の見た目を決めるファイルです。

- `components/ThemeBadge.vue` を追加しました。
  - スライド内で使える小さな部品の例です。

- `setup/README.md` を追加しました。
  - 今はセットアップ補足用の場所として作っています。

- `.gitignore` を追加しました。
  - Git で管理しないファイルを決める設定です。

## なぜこの構成か

1つの場所にテーマの定義をまとめるためです。

- テーマを使う人は、このリポジトリを `@your-org/slidev-theme-company` という名前で読み込みます。
- 1つのリポジトリで管理すれば、複数のスライド資料で同じルールを使えます。

# 使い方

このテーマを使う人向けの説明です。

## 1. このリポジトリでテーマを確認する

1. このリポジトリのルートで `npm install` を実行します。
2. `npm run dev` を実行します。
3. ブラウザが開き、`slides.md` の内容とテーマの見た目を確認できます。

## 2. 他のスライドリポジトリで使う

このテーマを別のリポジトリで使う場合は、次の2つを設定します。

### A. `package.json` に依存を追加する

他のスライドリポジトリの `package.json` に、次のように書きます。

```json
{
  "devDependencies": {
    "@your-org/slidev-theme-company": "~0.1.0",
    "@slidev/cli": "^0.53.0"
  }
}
```

### B. スライドにテーマを指定する

スライドファイルの先頭に、次のように書きます。

```md
---
theme: "@your-org/slidev-theme-company"
---
```

## 3. テーマの更新を使うとき

テーマは公開済みのバージョンで使うのが安全です。

- `~0.1.0` のように書くと、同じマイナー版の中で安全な更新だけが使われます。
- 大きな変更があるときは新しいバージョンを作り、利用するリポジトリでバージョンを更新します。

## 4. 何を触るべきか

このリポジトリでは、主に次の場所を変更します。

- `layouts/default.vue` : スライドの見た目の骨組み
- `styles/theme.css` : 色や文字の装飾
- `components/` : スライドで使う共通の部品

その他は基本的に設定ファイルです。慣れないうちは直接触らなくて大丈夫です。
